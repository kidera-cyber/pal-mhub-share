# PAL M-HUB（社内共有版・ダミーデータ）

マーケティング業務司令塔ダッシュボード「M-HUB」の**社内共有用プレビュー**です。

## ⚠️ 本リポジトリの位置づけ
- 顧客会社名・メールドメイン・担当者名・メールアドレス等の**実データはすべてダミーに置換済み**です。
- 配信件数・開封/クリック/不達などの**集計数値はレイアウト確認用に保持**しています（施策の実傾向とは切り離してご覧ください）。
- 画面右下に「社内共有版（ダミーデータ）」バッジを常時表示しています。
- 実データ版は社内ローカル（非公開）で管理しています。本リポジトリには含まれません。

## 閲覧方法
- GitHub Pages: 公開URLをブラウザで開く（下記Pages設定後に発行）。
- ローカル: このフォルダで `python3 -m http.server 8731` を実行し `http://localhost:8731/index.html` を開く。
